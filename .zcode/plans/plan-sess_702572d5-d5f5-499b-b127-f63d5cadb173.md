# Kế hoạch: Nhập LaTeX tự động đính kèm ảnh + Xuất PDF tài liệu

## Tính năng 1 — Nhập .tex tự động chèn ảnh (ảnh cùng thư mục với file .tex)

**Nguyên lý:** Parser giữ lại tên file ảnh được tham chiếu trong `\image{scale}{caption}{ten_file.png}`. Khi nhập, người dùng chọn/kéo file .tex **cùng các file ảnh** trong thư mục → website ghép theo tên file → gắn `File` vào khối ảnh/câu hỏi → khi lưu tài liệu, ảnh tự tải lên Supabase Storage (tái dùng logic lưu hiện có ở `DocumentEditor.tsx:148-189`, không cần sửa).

### Sửa file

**1. `lib/document-types.ts`** — thêm trường tạm cho form:
- Khối image của `DocumentFormBlock`: thêm `sourceName?: string` (tên file tham chiếu trong .tex)
- `QuizQuestion`: thêm `imageSourceName?: string`

**2. `lib/latex-parser.ts`** — giữ lại tên file ảnh:
- `extractQuestionImageAndText` (dòng 84-91) trả thêm đường dẫn → 4 parser câu hỏi gán `imageSourceName` (chỉ lấy basename)
- `parseQuizBlock` (dòng 245-282): ảnh đứng trước câu hỏi giữ cả tên file, không chỉ caption
- Khối ảnh trong textblock/lesson/độc lập (dòng 400-454): gán `sourceName` từ `path`

**3. File mới `lib/tex-image-match.ts`:**
- `normalizeImageName`: basename, thường hóa NFC, thường hoa, jpg≡jpeg
- `matchImagesToPreset(preset, files)`: duyệt khối ảnh (chưa có `file`/`storagePath`) + câu hỏi (chưa có `imageFile`/`imageStoragePath`) có `sourceName`, gắn `File` khớp; trả `{ matched, missing[] }`; chỉ nhận JPEG/PNG/WebP ≤ 5MB (khớp validation hiện có)

**4. `components/DocumentJsonTools.tsx`:**
- Input + drop zone nhận **nhiều file cùng lúc** (.tex + ảnh; `.json` giữ luồng cũ)
- Luồng mới: parse .tex → tự ghép ảnh đã cung cấp → nếu còn thiếu: hiện panel danh sách ✓/✗ kèm nút "📂 Chọn thêm ảnh" (input multiple) và nút "Nạp luôn (bỏ qua ảnh thiếu)" → xác nhận thay thế → `onApply`; thông báo thành công kèm "kèm M/N ảnh"
- Đổi dòng cảnh báo (dòng 226) thành mẹo: chọn .tex cùng các ảnh để tự động đính kèm

## Tính năng 2 — Xuất PDF qua trang in (đã chốt: hộp thoại In + công tắc đáp án)

**1. Route mới `app/tai-lieu/[id]/in/page.tsx`:** server component giống trang xem (kiểm tra đăng nhập, `getDocumentById`), render `DocumentPrintView`.

**2. Component mới `components/DocumentPrintView.tsx` (client):**
- Thanh công cụ `print:hidden`: công tắc "Hiện đáp án và giải thích" (mặc định tắt), nút "🖨 In / Lưu PDF" → `window.print()`, link quay lại
- Nội dung bản in: tiêu đề/mô tả/lớp, khối text & lesson qua `MathText` (KaTeX render sắc nét), ảnh + chú thích (`break-inside-avoid`), quiz **tĩnh**: trắc nghiệm A. B. C. D., đúng/sai từng mệnh đề, trả lời ngắn có dòng kẻ, tự luận có dòng trống; bật công tắc → đáp án đúng in đậm + hộp giải thích

**3. `components/DocumentViewer.tsx`:** thêm nút "⬇ Xuất PDF" (Link tới `/tai-lieu/[id]/in`) trong thẻ đầu trang.

**4. `app/layout.tsx`:** thêm `print:hidden` cho header, Sidebar, footer; bỏ padding main khi in.

**5. `app/globals.css`:** thêm `@page { size: A4; margin: 12mm }`, nền trắng chữ đen khi in, `color-adjust: exact`.

## Kiểm thử
- `npm run build` không lỗi
- Thủ công: nhập `templates/mau-tai-lieu.tex` + `templates/do_thi_don_dieu.png` cùng lúc → khối ảnh có file, lưu được tài liệu (không còn bị chặn như hiện tại); mở trang xem → Xuất PDF → kiểm công thức/ảnh/quiz, bật tắt đáp án
