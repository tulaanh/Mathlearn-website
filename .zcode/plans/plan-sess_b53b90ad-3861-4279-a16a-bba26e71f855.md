# Tối ưu giao diện học sinh cho đỡ lag

## Nguyên nhân gây lag (đã xác minh trong code)

**Khi làm bài / đọc tài liệu (client):**
1. `components/ExamRunner.tsx:153` — `onZoomImage` là arrow function inline (identity mới mỗi render) → vô hiệu hóa 2 bộ so sánh memo ở dòng 293 và 389 → **mỗi lần chọn đáp án / cắm cờ là re-render TOÀN BỘ đề thi** (mọi block, mọi câu hỏi, bảng câu hỏi mount 2 lần trên desktop).
2. KaTeX render đồng bộ cả đề lúc tải trang: `ExamRunner.tsx:26`, `QuizBlock.tsx:6`, `DocumentViewer.tsx` import `MathText` (render ngay), trong khi dự án đã có sẵn `LazyMathText` (chỉ render khi gần viewport) nhưng chỉ được dùng ở trang quản trị.
3. `QuizBlock.tsx` hoàn toàn không memo hóa — trả lời 1 câu re-render nguyên block.
4. `answeredUnits(questions, answers)` chạy lại O(toàn bộ câu hỏi) mỗi render (`ExamRunner.tsx:61`).

**Khi tải trang (server):**
5. `getLearningPathById` (`lib/learning-paths.ts:54-55`) tải TOÀN BỘ chương + items trong DB rồi mới lọc theo path — mỗi lần xem 1 lộ trình.
6. `loadDocumentCards` (`lib/documents.ts:231-235`) tải tất cả dòng documents rồi slice trong JS, tổng = rows.length (phân trang giả).
7. Trang kết quả (`app/quiz/[id]/result/page.tsx:17`) tải toàn bộ đề (cả blocks + JSON quiz) chỉ để lấy `title` — kết quả thật nằm trong sessionStorage.
8. `app/quiz/[id]/page.tsx:15` — `generateStaticParams` chết, mâu thuẫn với `force-dynamic`.
9. `getChapters()` (`lib/chapters.ts:53-80`) dùng 2 query tuần tự dù có thể gộp 1 query lồng.

## Thay đổi

### A. Client — sửa lag khi làm bài
1. **`components/ExamRunner.tsx`**
   - Bọc `onZoomImage` bằng `useCallback` (mở khóa toàn bộ memo có sẵn — fix 1 dòng, tác động lớn nhất).
   - `useMemo` cho `answered`, `essayCount`.
   - Đổi `MathText` → `LazyMathText` ở các chỗ nặng: đề bài, options, phát biểu đúng/sai, giải thích, khối text/lesson.
2. **`components/QuizBlock.tsx`** — tách phần render mỗi câu hỏi thành component con `React.memo` (props: question, index, answer của riêng câu đó, submitted, callback ổn định) → trả lời 1 câu chỉ re-render câu đó. Đổi `MathText` → `LazyMathText`.
3. **`components/DocumentViewer.tsx`** — `MathText` → `LazyMathText`.
4. **`components/QuestionPalette.tsx`** — bọc `React.memo`.
5. Giữ `MathText` render-ngay trong `DocumentPrintView.tsx` để bản in không bị thiếu nội dung (LazyMathText phụ thuộc viewport).

### B. Server — giảm thời gian tải trang
6. **`lib/chapters.ts`** — gộp 2 query thành 1 query lồng `chapters → chapter_items(*, documents(...))`; thêm tham số lọc `pathId` (optional).
7. **`lib/learning-paths.ts`** — `getLearningPathById` dùng đường lọc `.eq("path_id", id)` thay vì tải tất cả chương.
8. **`lib/documents.ts`** — phân trang thật: 1 query head-count lấy tổng + `.range(from, to)` áp dụng trong query factory; sửa contract của factory để truyền range vào.
9. **Trang kết quả** — thêm hàm nhẹ `getTestMetaById` (chỉ select `id, title, status, document_type`) thay cho `getDocumentById` toàn bộ trong `findTestDocument` của result page.
10. **`app/quiz/[id]/page.tsx`** — xóa `generateStaticParams` chết.

### C. Không làm (theo lựa chọn của bạn)
- Không thêm cache TTL (dữ liệu luôn mới sau khi giáo viên sửa).
- Không đổi URL ảnh — giữ `loading="lazy"` như hiện tại.
- Không đổi giao diện hay hành vi người dùng.

## Kiểm chứng
- `npm run build` kiểm tra type + build production thành công.
- Chạy dev server, smoke-test các trang học sinh: `/`, `/chuong`, `/chuong/[id]`, `/lo-trinh`, `/lo-trinh/[id]`, `/quiz`, làm 1 bài test (chọn đáp án, cắm cờ, nộp bài, xem kết quả), `/tai-lieu/[id]`.
- Lưu ý cho bạn: dev mode (`npm run dev`) luôn chậm hơn nhiều so với thực tế; để cảm nhận đúng hãy chạy `npm run build && npm start`.
